# MapNest Smart Contract

A decentralized platform for discovering and sharing hidden gems in cities.

## Features
- Add and manage Points of Interest (POIs)
- User review and rating system with automatic average calculation
- POI verification mechanism
- Reward system for contributors
- Input validation for ratings (1-5 scale)

## Contract Functions
- `add-poi`: Add a new Point of Interest (earns 100 points)
- `add-review`: Add a review for a POI (earns 10 points)
- `verify-poi`: Verify a POI (by authorized verifiers)
- `claim-rewards`: Claim accumulated reward points
- `add-verifier`: Add a new verifier (owner only)

## Reward System
- Adding a POI: 100 points
- Adding a review: 10 points
- Points can be claimed using the claim-rewards function
